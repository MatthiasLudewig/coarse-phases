# Geometric module

A geometric module is a Hilbert space with a locality structure depending on a {prf:ref}`bornological coarse space <def-bornological-coarse-space>`.
Concisely, it is a {prf:ref}`controlled object <def-controlled-object>` in Hilbert spaces.
There is also a notion for metric spaces, which is slightly more general and uses the topological structure induced by the metric.

## Hilbert-space-valued controlled objects

Let $(X, \mathcal{C}, \mathcal{B})$ be a {prf:ref}`bornological coarse space <def-bornological-coarse-space>`.

```{prf:definition} Point-determined geometric module
:nonumber:
:label: def-geometric-module

A *geometric module* over $X$ or *$X$-module* is a {prf:ref}`local <def-local-controlled-object>` {prf:ref}`controlled object <def-controlled-object>` in the category of separable Hilbert spaces.
```

Spelling out the definition, we obtain the following:

```{prf:definition} Geometric module
:nonumber:
:label: def-geometric-module-spelled-out

A *geometric module* over $X$ is a Hilbert space $H$ together with a closed subspace $H_Y \subseteq H$ for each subset $Y \subseteq X$ such that
1. whenever $Y \subseteq Y'$, then $H_Y \subseteq H_{Y'}$;
2. whenever $Y \cap Y' = \emptyset$, $H_Y$ is orthogonal to $H_{Y'}$;
3. whenever $(Y_i)_{i \in I}$ is a collection of subsets of $X$ with union $Y$, $H_Y$ is generated by the subspaces $H_{Y_i}$.
4. $H_B$ is separable whenever $B$ is bounded;
5. $H_X = H$.
```

Being determined on points is equivalent to the cocontinuity hypothesis in the {prf:ref}`definition of controlled objects <def-controlled-object>`.

```{prf:definition} Controlled operator
:nonumber:
:label: def-controlled-operator

Let $H$ and $H'$ be two $X$-modules.
A bounded operator $T: H \to H'$ is *$E$-controlled* if it sends $H_Y$ to $H'_{Y_E}$ for every $Y \subseteq X$.
$T$ is *controlled* if it is $E$-controlled for some entourage $E$.
```

$X$-modules and controlled operators form a category $\mathrm{Hilb}(X)$.
It is a dagger category with the usual adjoint of linear maps.

On any $X$-module $H$, there is a unique action of the algebra of bounded functions on $X$ with the property that the indicator function of a subset $Y \subseteq X$ acts as the orthogonal projection onto $H_Y$.

## Ample modules

```{prf:definition} Ample geometric module
:nonumber:
:label: def-ample-module

An $X$-module $H$ is called *ample* if there exists an entourage $E$ such that $H_{E[x]}$ is infinite-dimensional for each $x \in X$, where $E[x] = \{y \in X \mid (x, y) \in E\}$.
```

Ample $X$-modules exist if and only if there exists an entourage $E$ such that every {prf:ref}`$E$-separated subset <def-E-separated>` meets each bounded subset in at most countably many points.
Any two ample $X$-modules are isomorphic, in the sense that there exists a controlled unitary isomorphism between them.
For a proof, see [Bunke–Engel, Homotopy theory with bornological coarse spaces, Section 8.2, Definition 8.13, Proposition 8.20, and Lemma 8.21](https://arxiv.org/abs/1607.03657).

If $H$ is an ample $X$-module, any $X$-module $H'$ admits a controlled isometric embedding into $H$.

## On metric spaces

If $(X, d)$ is a proper metric space, one has the following more general definition.

```{prf:definition} Geometric module on metric spaces
:nonumber:
:label: def-ample-module-metric space

A *geometric module* over a proper metric space $X$ is a separable Hilbert space $H$ together with a non-degenerate representation of the algebra $C_0(X)$ of continuous functions on $X$ vanishing at infinity.
```

Non-degeneracy means here that $H$ does not contain elements on which the action of $C_0(X)$ is trivial.

By Borel functional calculus, the action of $C_0(X)$ extends by strong continuity to the algebra of bounded Borel functions on $X$.
For each Borel-measurable subset $Y \subseteq X$, the action of the indicator function of $Y$ yields an orthogonal projection in $H$.
Denoting the image of this projection by $H_Y$, we *almost* obtain the structure of a geometric module, except that $H_Y$ is only defined for measurable subsets and condition 3. is not satisfied.
